# 项目管理 MVP Web 应用

## 业务需求

本项目正在构建一个项目管理应用。核心功能：
- 用户可以登录
- 登录后，用户可以看到代表其项目的看板（Kanban）
- 看板包含固定数量的列，列可以重命名
- 看板上的卡片支持拖拽移动，也可以编辑
- 侧边栏内置 AI 聊天功能；AI 能够创建 / 编辑 / 移动一张或多张卡片

## 限制条件

MVP 阶段仅提供用户登录（硬编码为 'user' 和 'password'），但数据库将支持多用户，以便后续扩展。

MVP 阶段每个登录用户仅拥有 1 个看板。

MVP 阶段在本地运行（Docker 容器中）。

## 技术决策

- 前端使用 NextJS
- 后端使用 Python FastAPI，并在 / 路径托管静态 NextJS 站点
- 所有内容打包进一个 Docker 容器
- Docker 容器内使用 "uv" 作为 Python 包管理器
- AI 调用使用 OpenRouter。OPENROUTER_API_KEY 存放在项目根目录的 .env 文件中
- 模型使用 `openai/gpt-oss-120b`
- 数据库使用本地 SQLite，若数据库不存在则自动创建
- 启动与停止脚本（支持 Mac、PC、Linux）放在 scripts/ 目录

## 起点

前端 MVP 已构建完成，位于 frontend 目录中。该版本尚未针对 Docker 部署设计，目前仅为纯前端演示。
